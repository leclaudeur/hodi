# AI, if you like

The admin adds an API key in _Settings › AI & credits_ (Claude, from Anthropic, today). Billing is by use, on the key
owner's account, apart from any chat subscription. Every AI feature runs only after a click on a **purple button**,
never on its own:

- **Sum up**: the gist of an article, made once and kept.
- **Ask a question**: about an article, answered from it and from a few web searches when needed, with their links.
- **Daily summary**: the day's news, topic by topic, for the profile. It can be updated once it is 30 minutes old.
- **A plugin's purple button**: a signed plugin with the permission asks one question per click. It is never shown to
  a teen or a child.

Daily caps protect the credits. The household has 100 summaries, 100 questions, 8 daily summaries and 20 plugin requests
a day, shared equally between its profiles, and each plugin 10 an hour.

_AI & credits_ shows what each profile used, and the admin can reset a counter. Once a plugin has a purple button, the
page lists it with its calls of the last 24 hours and a switch to turn its AI off for the household.
