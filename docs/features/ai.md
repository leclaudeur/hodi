# AI, if you like

Each adult adds their own API key in _My account › AI and credits_ (Claude, from Anthropic, today); the key of the
first-run screens is the admin's. Billing is by use, on the key owner's account, apart from any chat subscription. A
young profile has no account, so no AI. Every AI feature runs only after a click on a **purple button**, never on its
own:

- **Sum up**: the gist of an article, made once per account and kept for it.
- **Ask a question**: about an article, answered from it and from a few web searches when needed, with their links.
- **Daily summary**: the day's news, topic by topic, for the profile. It can be updated once it is 30 minutes old.
- **A plugin's purple button**: a signed plugin with the permission asks one question per click. It is never shown to
  a teen or a child.

Daily caps protect the credits. Each account has 100 summaries, 100 questions, 8 daily summaries, 10 source
suggestions and 20 plugin requests a day, and each plugin 10 an hour.

_AI and credits_ shows the account's own calls of the last 24 hours, which it can reset, and its country, used for
the AI's web searches. Once a plugin has a purple button, the admin's page lists it with their calls of the last 24
hours and a switch to turn its AI off for the household.
